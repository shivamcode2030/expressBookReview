# Online Book Review Application

This repository is the completed IBM Skills Network Node.js and Express final project.

Forked from:
`ibm-developer-skills-network/expressBookReviews`

The completed application is in `final_project/`.

## Features

- Retrieve all books
- Search by ISBN
- Search by author
- Search by title
- Retrieve book reviews
- Register new users
- Login with JWT and Express sessions
- Add or modify reviews for the logged-in user
- Delete only the logged-in user's own reviews
- Async/Await + Axios implementations for all four required Node.js book-retrieval methods

## Run

    cd final_project
    npm install
    npm start

The server runs on port 5000 by default.
